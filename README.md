# 😍 Search Emojee JS 😍

A fun and interactive **Emoji Search Application** built with **HTML, CSS, and JavaScript**.  
Easily browse, search, and filter emojis by categories to find the perfect one!

👉 **Live Demo**: [Search-Emojee-JS](https://monisasmal.github.io/Search-Emojee-JS/)

---

## ✨ Features

- 🔍 **Search Bar** – Quickly find emojis by typing keywords.  
- 📂 **Categories** – Browse emojis by category (Face, Heart, Book, Hand, Sports, Flag).  
- 🎨 **Clean UI** – Responsive grid layout with modern styling.  
- ⚡ **Fast & Simple** – No frameworks, just pure **HTML, CSS, and JavaScript**.
